# 🌃 Portafolio Profesional Cyberpunk // IA & Desarrollo Web

Proyecto desarrollado como primera práctica para la asignatura de **Inteligencia Artificial**. Consiste en un portafolio web responsivo con estética **Cyberpunk** construido desde cero utilizando tecnologías web estándar y desplegado en la nube mediante **GitHub Pages**.

🔗 **Demo en vivo (GitHub Pages):** [https://kratostechrd.github.io/portafolio-cyberpunk/](https://kratostechrd.github.io/portafolio-cyberpunk/)

---

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica del sitio (Navegación, Hero, Perfil, Proyectos y Contacto).
* **CSS3:** Diseño personalizado con variables CSS, efectos *Glitch*, sombras neón (`#00f3ff`, `#ff0055`) y recortes geométricos (`clip-path`).
* **Bootstrap 5:** Sistema de cuadrícula (*Grid System*) para garantizar un diseño 100% responsivo en dispositivos móviles, tablets y escritorio.
* **JavaScript (ES6):** Animación dinámica de máquina de escribir (*Typewriter*) e interactividad en el formulario de contacto.

## 📖 Bitácora de Desarrollo (Mini-Blog)
1. **Conceptualización y Diseño:** Se eligió la temática Cyberpunk por su estrecha relación con la Inteligencia Artificial, la cibernética y el futurismo. Se seleccionaron tipografías monoespaciadas y geométricas (`Orbitron` y `Share Tech Mono`).
2. **Maquetación Responsiva:** Se integró Bootstrap 5 vía CDN para estructurar las tarjetas de proyectos y barras de progreso de habilidades sin comprometer la estética oscura personalizada.
3. **Interactividad:** Se programó un script ligero en JavaScript puro para dinamizar la presentación del perfil profesional y validar el envío de mensajes.
4. **Despliegue Continuo:** Se creó un repositorio público en GitHub y se habilitó GitHub Pages desde la rama `main` para obtener una URL pública accesible desde cualquier navegador.
